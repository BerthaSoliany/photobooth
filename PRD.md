# Self Photobooth with Custom frame
## Reference
./photobooth-webapp

## Functional Requirement
1. Mengambil gambar dengan kamera laptop.
2. Menyatukan hasil tangkapan gambar kamera dengan custom frame yang dimiliki.
3. Fitur download hasil.
4. Fitur mengirim hasil ke email dalam bentuk attachment email.

## Non-Functional Requirement
1. Dapat menggunakan kamera bawaan laptop ataupun kamera webcam yang dihubungkan ke laptop.
2. Program mudah digunakan dengan cara hanya ada beberapa fitur saja yang terlihat jelas.
3. Dapat di-deploy menggunakan github pages

## Notes
- Gunakan kode sesimpel mungkin, tidak perlu menggunakan framework yang tidak perlu
- Hanya ada 1 slot gambar (1 frame untuk 1 gambar).
- Tidak perlu ada fitur filter dan sticker.
- Tidak perlu ada homepage. Hanya ada page untuk mengambil foto dan melihat hasil.
- Tidak perlu ada styling pada page. Gunakan saja warna yang ada di custom-frame kalau mau menggunakan background color.
- Tidak perlu ada styling untuk button atau apapun itu juga. gunakan saja default atau gunakan styling yang sederhana saja
- Jangan gunakan asset yang ada di /photobooth-webapp
